# Reaktionstraining

Diese App ist ein interaktives Training für deine Reaktionszeit, Konzentration und Gedächtnisleistung. Sie bietet drei verschiedene Spielmodi, die jeweils unterschiedliche Fähigkeiten testen:

1. Klassisches Reaktionsspiel

Eine LED leuchtet auf und du musst so schnell wie möglich den zugehörigen Button drücken.

Die App misst dabei deine Reaktionszeit in Millisekunden und zeigt die beste Zeit sowie die Verteilung der Reaktionszeiten aller Spieler.

Ziel: deine Reaktionszeit kontinuierlich verbessern und dich mit anderen Spielern vergleichen.

2. F1-Startsimulation

Hier wird die Reaktionsfähigkeit im Start eines Formel-1-Rennens simuliert.

Sobald die Startampel erlischt, musst du den blauen Button drücken.

Die App zeigt deine beste Startreaktion, die Durchschnittswerte aller Spieler und unterstreicht, wie entscheidend schnelle Reaktionen beim Start sein können.

Ziel: deine Startreaktionen optimieren und realistische Rennsituationen üben.

3. Memory Game

In diesem Modus musst du dir eine LED-Sequenz merken und sie anschließend in der richtigen Reihenfolge wiederholen.

Bei korrekter Wiederholung wird die Sequenz länger, wodurch dein Gedächtnis und deine Konzentration trainiert werden.

Die App speichert deinen persönlichen Highscore und zeigt die Highscores aller Spieler in einem Diagramm.

Ziel: so viele Level wie möglich schaffen und deinen persönlichen Rekord übertreffen.
